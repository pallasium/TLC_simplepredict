# rf_calc — TLC の Rf と溶媒比から、目標の Rf になる溶媒比を見積もる

シリカゲル TLC 1 枚の Rf と溶媒比（体積比）から、**同じ化合物**で目標の Rf になる溶媒比を、手計算と同じ式で見積もる小さな対話式ツール。Python の標準ライブラリだけで動く（追加のインストールは不要）。

```
python rf_calc.py
```

## 2 つのモード

| モード | やること |
|---|---|
| 1 | 同じ溶媒系で、混合比を変える（例：ヘキサン/AcOEt の比を変えて Rf を上げる） |
| 2 | 別の溶媒系に移す（例：ヘキサン/AcOEt → トルエン/アセトン） |

どちらも、2 枚目（別の比で測った Rf）を入力すると、未知の係数が実測から決まり、答えが 1 つになる。入力しないと、もっともらしい範囲の両端（2 つの結果）が出る。

溶媒は、番号でも名前（大文字小文字は区別しない）でも選べる。

## 使っている式

- `R_M = log10((1 − Rf) / Rf)`
- **モード 1**：`R_M = a − n·log10(X_B)`（`X_B`：強溶媒のモル分率、`n`：1〜2 くらい）。体積比は、溶媒のモル体積でモル分率に直す。
- **モード 2**：Snyder の溶離力 ε°（シリカ）と、Snyder–Soczewiński の混合則で、混合溶媒の ε_mix を計算する。ε_mix が同じなら、似た保持になると考える。目標の Rf に必要な ε_mix の変化は、`Δε = ΔR_M / s` で出す。`s` は、2 枚目がなければ「ε が 0.05 変わると k′ が 2〜3 倍」という経験則（s = 6.0〜9.5）の範囲を使う。

## 使える溶媒

モード 1 は 14 種類（Hexane、AcOEt、CHCl3、MeOH、CH2Cl2、Toluene、Et2O、Acetone、THF、MeCN、EtOH、2-Propanol、Benzene、Dioxane）、モード 2 は、シリカの ε° がある 11 種類（EtOH と Benzene を除く）。溶媒は、`rf_calc.py` の `MOLAR_VOLUME` と `EPS_SILICA` に足せる。

## 限界

- **実測での検証ではずれることが多かった。** この計算は、一般的な式と経験則を、そのまま実装したもの。このツールの予測は目安として使い、新しい溶媒比では、必ず 1 枚測って確かめる。
- 同じ化合物・同じプレートの話。別の化合物や、別のロットのプレートには使えない。
- モード 2 は、溶媒の選択性（水素結合の受容・供与など）の違いを考えていない。ε_mix が同じでも、Rf は大きくずれることがある。
- 混合溶媒の吸着面積 n_b は、分子体積からの近似（`n_b = 6.0·(V/89.4)^(2/3)`）。α は 0.57 に固定している。
- 溶媒は、2 成分の混合（弱い溶媒 + 強い溶媒）だけ。

## 数値の出典

- 溶離力 ε°（シリカ）：L. R. Snyder, in *High-Performance Liquid Chromatography* Vol. 3 (C. Horváth ed., Academic Press, 1983)、および Burdick & Jackson *Solvent Guide* 3rd ed. (1990) の表（教科書に引用されたもの）。原著は直接確認していない。
- モル体積：H. Zeng ら、*Polymer Handbook* の溶解度パラメータの章（cm³/mol）。
- 式：L. R. Snyder, *Principles of Adsorption Chromatography* (Dekker, 1968)、E. Soczewiński の混合溶媒の式。
